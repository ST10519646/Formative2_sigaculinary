Project Overview

Siga Culinary is a unique Mexi-Kasi restaurant based in Alexandra, Johannesburg. The restaurant combines Mexican-inspired flavours with local South African township food culture to create a distinctive and welcoming dining experience.

The purpose of this website is to introduce Siga Culinary to customers, communicate its food and brand identity, display its menu and food gallery, provide booking information, and share restaurant news and updates.

The website was developed using HTML and CSS in Visual Studio Code.

────────

Website Goals

The main goals of the Siga Culinary website are to:

1. Introduce Siga Culinary and its food concept.
2. Provide customers with clear information about the restaurant.
3. Display the restaurant’s menu and food offerings.
4. Showcase food and restaurant images through a gallery.
5. Allow customers to make or enquire about bookings.
6. Share restaurant news and updates.
7. Create a visually appealing and easy-to-navigate website.

────────

Website Objectives

The website objectives are to:

• Create a clear and professional online presence for Siga Culinary.
• Make restaurant information easy for visitors to find.
• Use consistent colours, typography and spacing throughout the website.
• Provide simple navigation between all main pages.
• Present food information in a readable and attractive format.
• Include images that support the restaurant’s brand and identity.
• Create a responsive layout that can work on different screen sizes.

Key Features and Functionality

Navigation

The website includes navigation links to the main pages:

• Home
• About Us
• Menu
• Gallery
• Bookings
• News

Home Page

The home page introduces Siga Culinary and provides an overview of the restaurant.

About Us Page

The About Us page explains the restaurant’s concept, story and food philosophy.

Menu Page

The Menu page presents food and drink options with descriptions and prices.

Gallery Page

The Gallery page displays images of food and the restaurant. CSS hover effects are used to make the images interactive.

Bookings Page

The Bookings page provides customers with a booking form and information needed to make a reservation enquiry.

News Page

The News page provides restaurant updates, announcements and other relevant information.

Design and Visual Style

The website uses a warm and modern restaurant-inspired visual style.

Typography

The website uses:

• Playfair Display for elegant headings.
• Poppins for clean and readable body text.

Colour Scheme

The colour palette uses warm, natural and food-inspired colours, including:

• Dark brown
• Cream
• White
• Warm orange/brown accents

Layout

The layout uses:

• Flexbox for navigation and alignment.
• CSS Grid for the gallery.
• Cards for menu items.
• Rounded corners for images and content areas.
• Hover effects for interactive elements.
• Consistent spacing and typography.
